# M7 execution plan: tracing and reliability

**Brief:** *LangFuse tracing of ticket-resolution flows; reliability hardening for order-system API flakiness (retries, fallback to human queue, circuit breaker).*

**Status:** Done (2026-10-11). Results: [milestones/m7](../../milestones/m7/README.md). The owner asked for M1–M8 to be completed without interruption.

## Decisions
| # | Decision | Why |
|---|---|---|
| M7-1 | **Tracing port** with a local JSONL adapter (always on) and a Langfuse adapter (on when `SHOPSENSE_LANGFUSE_*` keys are set). Every workflow node writes a span | The Langfuse account needs the owner's keys; the local adapter gives real, checkable traces now |
| M7-2 | **Masking before any trace is written**: emails, phone numbers, card and account-like digit runs are replaced | Traces leave the process when Langfuse is on (D13) |
| M7-3 | **Retries** in the MCP server for reads (GET) and, with the idempotency key, for refund writes; bounded backoff | LLD-4 L4f |
| M7-4 | **Circuit breaker** in the MCP server around Order Platform calls: opens after 3 consecutive failures, half-opens after 10 s | LLD-4 L4f; fast failure while the order system is down |
| M7-5 | **Fallback to a human queue**: a ticket whose order lookup or quote fails is parked (`parked_human_queue`) with a clear reply | Brief |
| M7-6 | **Outbox for approved writes** in the shopsense database: an approved refund is recorded before it is sent; a worker retries until it is settled | "No approved action is lost" (acceptance) |
| M7-7 | **Fault injection** in the Order Platform: `/admin/faults` sets an error rate or a delay for a fixed time, then expires by itself; admin token required | The demo needs controlled faults; expiry means a forgotten fault cannot stay on |

## Acceptance
- Resilience suite: the breaker opens under sustained faults and closes after recovery; retries recover transient errors.
- No approved refund is lost: every approved refund reaches `processed` once faults stop (outbox drains).
- Every ticket turn has a trace with masked inputs and outputs.
- ruff, mypy strict, pytest pass.

## Deferred
- Application Insights and the APIM AI gateway (enhancements, not brief).
- Langfuse cloud evidence (needs the owner's keys; the adapter is in place).
